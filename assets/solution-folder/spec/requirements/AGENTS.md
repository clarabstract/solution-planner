# Requirements

Files in this folder include test cases that check later work independently.

Unless you're planning this solution or editing cases at the user's request, you shouldn't be reading them. If you've seen a case, stop and tell the user, so the work can move to a new session.

To get the requirement statements without the cases, run the script for your system from the solution folder, two levels up:

- Windows: `powershell -ExecutionPolicy Bypass -File scripts\list-requirement-statements.ps1`
- macOS or Linux: `sh scripts/list-requirement-statements.sh`
